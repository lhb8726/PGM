**PGM 프로토타입 v0.1 사용 안내**

이 버전은 현재 상태 입력부터 목표·계획·실행·회고·백업까지 연결해 검토하기 위한 로컬 데스크톱 프로토타입입니다. 최초 요구사항은 [요구사항 및 개발계획](requirements-v0.1.md)에 보관합니다. 이 문서는 기능의 실제 범위와 제한을 설명합니다.

**처음 사용할 때**

1. 저장소 루트의 macOS 또는 Windows 실행기를 실행합니다. Python 3.10 이상이 필요하며, 처음에는 가상환경과 필수 패키지를 준비합니다.
2. 화면 구조를 먼저 확인하려면 가상환경에서 `python -m pgm --demo`로 실행합니다. 일반 데이터와 분리된 데모 저장소를 사용합니다.
3. 개인 데이터로 사용하려면 일반 실행 후 나의 프로필에 기본 정보·순가용 시간·자산 현황을 입력합니다.
4. 현재 상태 기록에서 분야별 지표와 출처·측정일·근거 유형을 추가합니다.
5. 목표를 등록하고 기한·우선순위·완료 기준을 설정합니다.
6. 로드맵 초안을 확인하고 실제 상황에 맞게 과제와 날짜를 수정한 뒤 실행합니다.
7. 실행 기록과 회고를 남기고 필요할 때 미완료 과제를 재계획합니다.

| 나의 프로필·진단 | 프로필·자산·가용 시간, 근거를 구분한 상태 기록과 기초 진단 |

**현재 상태와 진단의 의미**

기록에는 자기평가·직접 측정·시험 또는 결과물 등 근거 유형을 표시합니다. 자료가 없는 부분은 부족한 정보로 남깁니다. 기초 진단은 입력한 자료와 목표의 차이, 누락된 정보를 정리하는 규칙 기반 설명입니다. 임상 검사, 재무 자문, 타인 대비 역량 백분위 또는 합격·취업 확률로 해석하지 않습니다.

목표는 수치·결과물·반복 유형으로 관리합니다. 수치 목표는 시작값·현재값·목표값·단위·방향을 함께 기록합니다. 과제 수행률과 실제 목표 달성은 구분하며, 자격 취득 등 최종 결과는 직접 확인합니다.

수치 목표는 증가·감소 기준을 지원하며, 일정 범위를 유지하는 목표의 상·하한과 기간 준수율은 아직 별도 유형으로 구현하지 않았습니다. 프로필의 자산 금액은 현재값을 저장합니다. 날짜별 변화를 보존하려면 현재 상태 지표로 별도 기록해야 하며, 측정 지표의 장기 추이 그래프는 현재 제공하지 않습니다.

**계획 생성·재계획**

6개 분야가 같은 가용 시간을 공유합니다. 프로필의 주간 시간은 계획에 쓸 수 있는 순가용 시간으로 입력하세요. 기본 계획 엔진은 이 시간을 7일에 균등 배분하고 분 단위로 내림한 뒤, 등록된 과제와 습관 시간을 반영해 새 과제를 배치합니다. 예를 들어 주당 7시간은 매일 60분으로 배분합니다. 실제 요일별 시간 차이와 시각별 약속은 반영하지 않습니다.

로드맵은 분야별 기본 단계에 따른 초안입니다. 필요한 실제 학습량이나 자격 요건을 자동 검증한 결과가 아니므로 과제 이름·예상 시간·완료 기준을 검토해야 합니다. 목표와 상황에 따라 직접 수정할 수 있습니다. 일정 배치가 불가능한 경우 경고와 미배치 과제를 확인하고 기한·범위·투입 시간을 조정합니다.

계획은 날짜와 총 소요 시간 기준입니다. 시작·종료 시각의 겹침, 외부 캘린더와의 충돌은 검사하지 않습니다. 프로필의 가용 예산과 현금흐름은 기록·진단에 사용하지만, 과제별 비용이나 전체 목표의 예산 초과를 계획 엔진이 검증하는 기능은 아직 없습니다.

재계획은 미완료 과제를 대상으로 하고 완료 기록을 보존합니다. 자동 초안의 단계 순서는 유지하되, 사용자가 선행 과제를 직접 연결하는 의존 관계 그래프와 순환 관계 검사는 아직 없습니다. 월간·주간·일간 전환은 같은 실행 과제를 예정일에 따라 묶어 보여주는 기능이며, 별도의 월·주 목표 계층을 자동 생성하지 않습니다.

가용 시간의 요일별 세부 분포·고정 일정·외부 캘린더·여러 통화·복잡한 자원 최적화는 이후 고도화 범위입니다. 동일한 행동을 습관과 별도 과제로 모두 등록하면 중복될 수 있으므로 한쪽에서 관리하세요. 일부 단계만 배치됐다는 경고가 있으면 해당 초안의 범위와 남은 단계를 직접 확인해야 합니다.

**기록 편집과 분석의 현재 범위**

목표·과제·습관은 추가·수정·삭제를 지원합니다. 삭제는 해당 항목의 수정 창에서 확인 후 실행하며, 목표를 삭제하면 연결 과제도 삭제됩니다. 상태 지표와 회고는 새 기록을 추가하는 흐름이며, 기존 기록 수정·삭제 화면은 없습니다. 습관의 휴식 요일은 설정할 수 있지만 특정 날짜 예외·일시중지는 아직 없습니다.

실행 차트는 과제의 예정일에 따른 계획·완료 수를 보여줍니다. 해당 날짜에 실제로 수행한 시간이나 실력이 향상된 정도를 나타내는 차트가 아닙니다. 목표 진행도의 동일 가중 평균은 등록한 목표 구성에 따라 변하며, 목표의 추가·삭제나 기준 변경을 통제한 장기 성장 지수는 아닙니다.

**AI와 자료 검색**

외부 AI API, API 키 설정, 자동 웹 검색은 아직 연결하지 않았습니다. AI 코치 화면의 현재 제안은 로컬 규칙 기반이며 외부 모델이 작성한 답변으로 표시하지 않습니다. 브라우저 검색은 사용자가 웹에서 자료를 확인하는 방식이고, 검색 결과를 앱이 자동 읽거나 사실 검증해 저장하는 기능은 아닙니다.

상담 요약 복사 기능은 프로필·목표·진척을 정리해 사용자가 다른 도구에 직접 전달할 수 있게 합니다. 복사한 자료를 외부 서비스에 붙여넣기 전 내용을 확인하세요. 현재 버전은 외부 모델에 프로필이나 자산 정보를 자동 전송하지 않습니다.

**저장과 기기 이동**

일반 실행 데이터는 운영체제의 사용자 앱 데이터 폴더에 저장합니다. `--data-dir`으로 경로를 지정할 수 있으며 실제 위치는 설정 화면에서 확인합니다. `--demo`에 별도 경로를 지정하지 않으면 일반 데이터와 분리된 데모 폴더를 사용합니다.

1. 원본 기기의 설정에서 백업을 내보냅니다.
2. 생성한 `.pgmbackup` 파일을 다른 기기로 옮깁니다.
3. 대상 기기에서 먼저 현재 데이터를 백업한 뒤 복원합니다.
4. 목표·기록·첨부 자료가 올바른지 확인합니다.

백업은 SQLite 스냅샷, 첨부 파일과 형식 정보를 담는 **암호화하지 않은 ZIP 파일**입니다. 민감한 정보가 들어 있을 수 있으므로 보관 위치를 선택해야 합니다. 현재 버전에는 백업 암호 보호·비밀번호 복구·실시간 동기화가 없습니다.

복원은 전체 교체이며 두 기기의 변경을 병합하지 않습니다. 복원 전 현재 데이터의 백업을 보관합니다. 잘못된 형식이나 유효하지 않은 데이터는 적용 전에 검사합니다. 다른 기기에서 사용하는 절대 경로에 의존하지 않도록 첨부 자료도 백업에 포함합니다.

첨부 폴더의 파일은 백업·복원에 포함하지만, 현재 UI에는 첨부 파일을 등록·삭제하는 전용 화면이 없습니다. 테마·알림 등 기기별 설정은 데이터 백업과 별도로 관리합니다.

**알림의 범위**

앱 실행 중 미완료 과제를 알려주는 범위입니다. 운영체제 알림 허용 상태에 따라 표시가 달라질 수 있습니다. 앱 완전 종료·PC 종료·절전 상태에서 예약 작업을 깨우는 기능은 구현 범위에 포함하지 않습니다.

**개발자가 확인할 실행 옵션**

```text
python -m pgm
python -m pgm --demo
python -m pgm --data-dir "별도 데이터 경로"
python -m pgm --demo --data-dir "별도 데모 경로"
python -m pgm --demo --screenshot "dashboard.png"
python -m pgm --demo --smoke-test
```

테스트에는 임시 데이터 폴더나 명시한 데모 폴더를 사용합니다. 기본 개인 데이터 폴더에서 복원 시험을 하지 않습니다. GUI 없는 환경은 `QT_QPA_PLATFORM=offscreen`을 설정합니다.

```text
python -m pip install -r requirements-dev.txt
python -m pytest -q
python scripts/build.py --dry-run
python scripts/build.py
```

빌드 도구는 실행 중인 Python으로 PyInstaller를 호출하며 `dist`에 폴더 형태 결과물을 생성합니다. Windows·Mac용 결과물은 각 OS에서 빌드해야 합니다. Mac의 Intel·Apple Silicon 대상과 최소 지원 OS는 실제 빌드·실행 결과에 따라 확정합니다.

검증 결과(2026-11-03): Python 3.12.2 · PySide6 6.12.0 · macOS arm64에서 자동 테스트 **54개 및 하위 검증 8개 통과**, 실제 macOS 앱 빌드와 8개 메뉴 실행 확인. Windows 실행·빌드는 이 로컬 환경에서 검증하지 않았습니다.
